HOW TO RUN
1. Extract the ZIP.
2. Open index.html in any current browser. For development, use the VS Code Live Server extension.
3. Edit index.html for content, styles.css for styling, and script.js for interactions.

INCLUDED SECTIONS
Hero / Featured Projects / Tech Stack / How I Work / Services / About / Contact.

FUNCTIONALITY
- Responsive navigation, active section tracking, and scrolling progress
- Project category filters and original project screenshot modal
- Contact form uses a mailto: action. It opens an email application; it does not send messages automatically.
- Copy email button, resume PDF, and verified contact links from your prior portfolio
- Reduced motion and keyboard accessible controls

ASSETS
The tech-stack, workflow and services visual crops are from AI-generated concepts and are illustrative, not screenshots of real deployed software. Project cards use your original screenshots; project modal uses them as well.

EDITING
Check your personal information before publishing, particularly the 4th year student label, and update your contact information as necessary. Google Fonts needs internet connectivity; system fonts are used as fallback.
